# Changelog

## 0.1.0a1 — experimental alpha

- Python 3.14 service and CLI with transient Redis, independent reducer workers, immutable observation state, and validated lifecycle authority.
- Pinned CPU Laya routing, hosted DREX typed decisions, GPT-4.1-mini reducers, and one GPT-5.1 call per escalation at gate-selected thinking effort.
- Explicit fractional telemetry units and authoritative typed-fact precedence over conflicting source notes or generated summaries, with contradictory-summary regression/numeric checks.
- Captured attempted-request IDs persist in gate eligibility after terminal operation/result review, preventing previously attempted submissions from becoming new operation candidates.
- Fixture and opt-in live demonstrations, contract/failure tests, private diagnostics, and curated historical qualification evidence.
- Release packaging, bundled synthetic routing corpus, public setup/contribution/security documentation, and 0BSD licensing for original code and documentation.

The [pre-cleanup qualification](docs/qualification/2026-10-12.md) recorded 9/10 runtime workflows but 6/10 combined factual successes, below the original live target. CPU throughput also failed the original target. Those historical limitations remain disclosed; [current release verification](docs/qualification/release-0.1.0a1.md) records any subsequent checks without replacing the frozen evidence.
